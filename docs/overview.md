# Phonebook — проектная документация

## Назначение

Phonebook — настольный телефонный справочник для Windows на C# и Windows
Forms. Данные хранятся локально в SQLite. Сетевой обмен контактами приложением
не выполняется.

## Возможности

- создание и редактирование контактов;
- поиск по имени, телефону, e-mail, заметкам, группе и дате рождения;
- сортировка столбцов и выбор строк флажками;
- удаление отмеченных контактов;
- импорт и экспорт CSV;
- импорт и экспорт vCard (VCF);
- объединение совпадающих контактов при импорте;
- предварительный просмотр и печать отмеченных контактов.

Контакт включает имя, телефон, e-mail, группу, заметки и необязательную дату
рождения. Обязательны имя и телефон.

## Технологии

| Компонент | Технология |
| --- | --- |
| Язык и платформа | C#, .NET 10 (`net10.0-windows`) |
| Интерфейс | Windows Forms |
| Хранение данных | SQLite через `Microsoft.Data.Sqlite` |
| Точка входа | `Program.cs` |

## Структура исходников

| Файл | Назначение |
| --- | --- |
| `Program.cs` | Инициализация WinForms и запуск главной формы |
| `Form1.cs` | Главная форма, отображение, операции, поиск, импорт/экспорт и печать |
| `Form1.Designer.cs` | Создание элементов интерфейса и регистрация обработчиков |
| `ContactEditForm.cs` | Форма создания/редактирования и проверки контакта |
| `PhonebookDatabase.cs` | Модель `Contact` и доступ к SQLite |
| `PhoneNumberFormatter.cs` | Нормализация и визуальное форматирование телефона |
| `Phonebook.csproj` | Целевая платформа и зависимости |
| `run_phonebook.cmd` | Сборка (если отсутствует exe) и запуск |
| `run_phonebook.bat`, `run_phonebook_auto.bat` | Альтернативные сценарии запуска |

## Сборка и запуск

Нужны Windows и .NET 10 SDK:

```powershell
dotnet build .\Phonebook.csproj
dotnet run --project .\Phonebook.csproj
```

Также можно запустить `run_phonebook.cmd`. Обычная сборка создаёт
`bin\Debug\net10.0-windows\Phonebook.exe`.

Рабочая база располагается рядом с исполняемым файлом. При запуске приложение
создаёт таблицу `Contacts`, если её ещё нет, и добавляет отсутствующие колонки
`Birthday` и `GroupName` для совместимости со старой схемой.
