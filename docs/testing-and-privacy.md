# Проверки, приватность и эксплуатация

## Автоматические smoke-тесты

В репозитории есть небольшой автономный набор проверок без внешнего test
framework. Запуск из корня:

```powershell
dotnet run --project .\tests\Phonebook.Tests\Phonebook.Tests.csproj
```

Набор проверяет разбор CSV с кавычками/переводами строк, определение разделителя,
разбор стандартного и legacy quoted-printable для кириллицы, нормализацию
телефона и операции добавления/объединения контактов в отдельной тестовой базе.
Тестовые контакты синтетические; созданная тестовая база удаляется по завершении.

Также проверяйте сборку:

```powershell
dotnet build .\Phonebook.csproj
```

## Приватность

- SQLite хранится локально рядом с исполняемым файлом.
- Приложение не отправляет контакты по сети.
- CSV, VCF, базы SQLite и артефакты IDE/сборки исключены в `.gitignore`.
- `.gitignore` не исключает файл, который уже был добавлен в индекс Git.
  Перед публикацией проверяйте `git status` и `git ls-files`.
- При удалении контактов приложение выполняет обычный `DELETE`; файловая база
  может сохранять свободные страницы до очистки/перестроения. Не публикуйте
  пользовательскую базу, даже если таблица визуально пуста.

## Резервное копирование и перенос

Перед обновлением, переносом или очисткой программы скопируйте `phonebook.db`
в безопасное место. Для передачи контактов используйте экспорт CSV/VCF и
храните получившийся файл так же внимательно, как базу: в нём содержатся
персональные данные.

## Известные ограничения

- Приложение нацелено на Windows и `net10.0-windows`.
- Дата в CSV, не соответствующая поддерживаемым форматам, считается пустой.
- Строка импорта без имени или телефона пропускается.
- Автоматическая синхронизация между устройствами не реализована.
