ТЕЛЕФОННЫЙ СПРАВОЧНИК
=====================

Настольное приложение для Windows, позволяющее вести локальную базу контактов.

Возможности
-----------
- Добавление, редактирование, поиск, сортировка и удаление контактов.
- Поля контакта: имя, телефон, e-mail, группа, заметки и дата рождения.
- Импорт и экспорт CSV.
- Импорт и экспорт vCard/VCF.
- Объединение совпадающих контактов по нормализованному имени и телефону.
- Предварительный просмотр и печать выбранных контактов.

Требования
----------
- Windows.
- .NET 10 SDK для сборки.
- .NET 10 Desktop Runtime для запуска приложения.

Сборка и запуск
---------------
Выполните команды из каталога проекта:

    dotnet build Phonebook.csproj
    dotnet run --project Phonebook.csproj

Либо соберите проект и запустите run_phonebook.cmd.

Приложение создаёт файл phonebook.db рядом с исполняемым файлом. Это локальная
база персональных данных; она исключена из Git. Сделайте резервную копию базы
перед переносом или переустановкой приложения.

Документация и тесты
--------------------
Каталог docs/ содержит описание архитектуры, схемы данных и алгоритмов,
форматов импорта/экспорта, приватности и проверок.

Запуск smoke-тестов:

    dotnet run --project tests/Phonebook.Tests/Phonebook.Tests.csproj

Приватность
-----------
Контакты хранятся локально в SQLite. Файлы базы, CSV/VCF и результаты сборки
исключены через .gitignore. Перед публикацией всё равно проверяйте список
файлов Git: правила .gitignore не исключают файлы, уже добавленные в индекс.
